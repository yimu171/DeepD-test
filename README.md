# DeepD homepage

Static homepage for **DeepD**, a sparse mixture-of-experts genome foundation model for efficient long-context DNA modeling and controllable sequence generation.

- Code, notebooks and API usage guide: <https://github.com/biomap-research/DeepD>
- API key requests: use the form in the *Resources* section of the site.

The site is plain HTML, CSS and JavaScript with no build step. Open `index.html` locally or serve the folder with any static file server.
